# Provenance of the vendored icon sources

Everything in `src/nerdfont/` is third-party artwork, vendored unmodified
from [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) at release
**v3.5.1**, commit `b894ea7803af6aade63d60a4381e006098ec9c4d`.

Nothing here is generated by this project, and nothing here reaches the base
font. It is used only by `make -f build/Makefile nf`, which builds the
separate `CADR Mono NF` family. See the Licence section of the README.

The table below is upstream's own, from `src/glyphs/README.md` at that commit.

## Two sets were deliberately removed

Nerd Fonts patches both of these; this project does not, so a build from here
is missing them. Both decisions are about redistribution, not quality.

**Font Logos** — the Linux distribution logos at `U+F300`–`U+F385`, 135
glyphs. Upstream's own table marks it `unlicensed`, and the font asserts
`Copyright (c) 2014-2026, Lukas W` with no grant anywhere in the file. The
absence of a licence is not a permissive one. If
[lukas-w/font-logos](https://github.com/lukas-w/font-logos) clarifies its
terms, dropping the file back into this directory is all that is needed —
`build/nerdfont.py` picks up whatever sources are present.

**Pomicons** — 13 glyphs at `U+E000`–`U+E00A`. Its documentation and its own
metadata disagree. Upstream ships an OFL-1.1 licence naming Gabriele Lana with
Reserved Font Name `Pomicons`; the font file says `Copyright (c) 2014 by
Davide Bignotti. All rights reserved.` and `Pomicons is a trademark of Davide
Bignotti.` A different holder, an all-rights-reserved notice and a trademark
claim is not something to resolve by assuming the friendlier document wins.

## Attribution is required, not optional

Of the sets that remain, only `PowerlineExtraSymbols.otf` states its licence in
its own metadata; the others name a copyright holder and nothing more, so the
grants rest on the table above and the files in this directory. Codicons and
Font Awesome are **CC BY 4.0**, which obliges attribution on every
distribution. Material Design is Apache 2.0 (licence and NOTICE preserved),
Weather Icons is OFL 1.1, and the remainder MIT (copyright and licence text
preserved). Ship this directory with any build you distribute.
